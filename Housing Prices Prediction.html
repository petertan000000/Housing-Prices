The objective of this project is to develop a machine learning regression model that predicts residential property prices using the features provided in the dataset. The training dataset contains 1,460 records and 81 columns, while the testing dataset contains 1,459 records and 80 columns. The target variable is SalePrice, which represents the selling price of a property.

Feature Engineering¶

Feature engineering was performed to generate additional information for the model.

Two new features were created:

HouseAge = YrSold - YearBuilt (This feature represents the age of the property at the time of sale.)

TotalSF = TotalBsmtSF + 1stFlrSF + 2ndFlrSF (This feature combines all major living areas into a single measurement representing the total usable floor space.)

The TotalSF feature became one of the strongest predictors of house price with a correlation of 0.782260, demonstrating that combining related variables can improve the ability of the model to capture useful information.

Maximum depth of the individual regression estimators. The maximum

min_impurity_decrease min_impurity_decrease: float, default=0.0

A node will be split if this split induces a decrease of the impurity
greater than or equal to this value.
Values must be in the range `[0.0, inf)`.

The weighted impurity decrease equation is the following::

N_t / N * (impurity - N_t_R / N_t * right_impurity
- N_t_L / N_t * left_impurity)

where ``N`` is the total number of samples, ``N_t`` is the number of
samples at the current node, ``N_t_L`` is the number of samples in the
left child, and ``N_t_R`` is the number of samples in the right child.

``N``, ``N_t``, ``N_t_R`` and ``N_t_L`` all refer to the weighted sum,
if ``sample_weight`` is passed.
